# Video script — maximum five minutes

## 0:00–0:30 — Context

“Hello. This is our Visualization Reports or Dashboard project. We created
Netflix Catalog Explorer, an interactive visual report built with Python,
pandas, Plotly, and Streamlit.”

## 0:30–1:15 — Repository and structure

Show the public repository and briefly point out app.py, data, requirements,
and .github/workflows/quality.yml.

“The repository contains the application, the versioned dataset, the
dependencies, and an automated quality workflow.”

## 1:15–2:45 — Live application

Open the published application and demonstrate the summary indicators, content
type filter, a country or genre filter, the release-year slider, the charts,
and the filtered table.

“The dashboard updates the indicators, charts, and table according to the
selected filters.”

## 2:45–3:45 — Automation

Show the GitHub Actions publication workflow and one successful run.

“On every push to the main branch, the workflow regenerates the Plotly report,
uploads it as a Pages artifact, and deploys it to GitHub Pages. A separate
quality workflow validates the Python application and dataset.”

## 3:45–4:30 — Individual contributions

Each member briefly states their contribution. Keep this section short so the
video stays below five minutes.

## 4:30–5:00 — Closing

“The project connects exploratory data visualization with a public repository,
automated validation, and cloud publication. The repository, live application,
and article links are included in the final delivery ZIP. Thank you.”
